# Connect your AI

Every app connects to the same address:

```
https://brain.mdcrypt.dev/mcp
```

The first time an app connects, you're sent to GitHub to **authorize "Second Brain MCP MDCrypt"**, then straight back. You sign in with GitHub; there's no separate password, and nothing to install.

<div class="grid cards" markdown>

-   :simple-anthropic:{ .lg .middle } __[Claude](claude.md)__

    Desktop app, claude.ai and the iPhone and Android apps. One setup covers them all.

-   :simple-openai:{ .lg .middle } __[ChatGPT](chatgpt.md)__

    Web, with a paid plan, through Developer mode. Works with deep research too.

-   :material-console:{ .lg .middle } __[Claude Code](claude-code.md)__

    One command in the terminal. Great for project docs and scheduled agents.

-   :material-robot-outline:{ .lg .middle } __[Hermes](hermes.md)__

    Your always-on agent, on a server, Telegram or the command line.

-   :material-puzzle-outline:{ .lg .middle } __[Other MCP clients](other.md)__

    Anything that speaks remote MCP with OAuth.

</div>

## After connecting, try

- *"What's in my second brain about* topic*?"*
- *"Research* topic *and save a summary to my second brain, with sources."*
- *"Add to today's daily note: called the plumber, quote is $400."*
- *"What changed in my vault this week, and who changed it?"*
- *"List my open tasks in Projects."*
- *"Check my vault's health."*

!!! tip "Give each agent a name"
    If you use several personas through one app, such as two Claude Projects, give each a name so its changes are signed separately. See [Name your agents](../guides/named-agents.md).
