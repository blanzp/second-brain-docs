# Troubleshooting

| What you see | What it means and what to do |
|---|---|
| Sign-in: *"&lt;you&gt; is not invited to this server"* | You're not on the invite list yet. [Request access](../get-started/access.md). |
| Sign-in: *"Install the … GitHub App on &lt;repo&gt; first"* | [Install the app](../get-started/github-app.md) on the repo you gave when you requested access. |
| Sign-in: *"&lt;you&gt; can't access &lt;repo&gt; through the app"* | The app is installed, but not on that repo: **Configure** the app and add the repo. |
| An AI app says it can't connect, or 401 | Disconnect and reconnect the connector to sign in again. |
| An AI app doesn't see a new tool or field | Start a new chat; if needed, turn the connector off and on. |
| New notes from an AI don't show in the web app | Pull down at the top of the screen to refresh. |
| *"A note already exists at …"* | The AI tried to create a duplicate. Ask it to add to the existing note. |
| *"Too many requests"* | More than 120 requests in a minute. Wait a minute. |
| *"This note changed since you opened it"* | Someone (or an agent) edited it while you were editing. Choose which version to keep; nothing is overwritten silently. |
| A note shows *"Offline · saved copy from …"* | You're offline or the connection is slow; you're seeing the copy saved on your device. |
| A diagram shows its source and an error | The diagram's code has a mistake. Ask the agent that wrote it to fix it. |
| Changes made elsewhere are missing | Ask an agent to *check recent changes*. The safety net flags anything that rolled notes back. |
