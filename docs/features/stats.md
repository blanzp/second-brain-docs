# Usage stats

See how you and your agents use Unibrain. Open **⚙ Settings → Usage stats**.

## Your activity

- **Commits per day** as a chart, for 7, 30 or 90 days. Tap a bar to read its value.
- **Who made the commits:** you in the web app, each app, and each named agent, ranked.
- **Apps you used**, by number of requests.
- **Your vault:** notes, attachments, size and open todos, counted nightly.
- Files added, changed, moved and deleted, and any safety-net alerts.

Today's numbers update as you go: pull down to refresh.

## Private by design

Only **counts** are kept: requests, commits, tools used, durations. **Never** note contents, titles, paths, searches or commit messages. You see your own numbers; nobody else's.
