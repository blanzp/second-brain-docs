# Tasks

Write todos where they belong, in the note about the project, the trip or the house. The **Tasks** page pulls them all together.

## Todos, not lists

Checkboxes mean two things, and Unibrain keeps them apart:

- **Todos** are things to do. Any `- [ ]` in an ordinary note is a todo.
- **Lists** are sights to see, things to pack, steps in a plan. Tag the note as a list (for example `#itinerary` or `#checklist`) and its checkboxes stay off the Tasks page.
- A real action inside a list gets `#todo` on its line and shows up anyway:

```markdown
- [ ] Siena: Piazza del Campo
- [ ] Book the winery tour #todo 📅 2026-10-05
```

Which tags count as lists is up to you, in [Vault settings](settings.md).

## Due dates

Add a due date in the Obsidian Tasks format, `📅 YYYY-MM-DD`, at the end of the line. Overdue and due-today items get red and orange badges, and notes with the soonest due task come first.

## The Tasks page

- One **collapsible section per note**, with open, overdue and due-today counts in its header. The sections you open are remembered on your device.
- **Expand all** and **Collapse all**.
- **Tick in place:** the checkbox in the note itself is updated and committed.
- **Filter** by any word; matching sections open automatically.
- **Show done** to see what's finished.
- Archived notes stay out of the way.

Agents use the same tasks: *"What's overdue?"*, *"Tick off the winery booking."*
