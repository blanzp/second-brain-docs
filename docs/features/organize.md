# Organizing

Reorganize freely: links never break.

## Move and rename

- **Notes and folders** can be moved and renamed by you (the **Organize** button on a note) or by any agent.
- **Every link to them is rewritten across the vault**, in the shortest form Obsidian understands, keeping headings, block links, aliases and embeds.
- Moving into a folder that doesn't exist creates it.

## Tags

- **Retag** a note from the Organize panel.
- Agents can **rename a tag across the whole vault** in one step, including nested tags (`trip/italy` follows `trip`). Renaming onto an existing tag merges them.

## Archive, don't delete

- **Archive** moves a note or folder to `Archives/` under the same path: `travel/Old Trip.md` becomes `Archives/travel/Old Trip.md`.
- **Unarchive** puts it back exactly where it was.
- In the web app, archiving offers **Undo** right away.
- Archived notes stay out of Tasks and kept-offline folders.

## Keep it healthy

Ask an agent to *check vault health*: broken links, orphan notes, note names shared by several files (which make links ambiguous), empty notes and problems in your settings.
